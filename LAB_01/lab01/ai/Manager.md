# AI Role: Manager

## Роль
Manager відповідає за планування та контроль виконання лабораторної роботи.

## Обов'язки
- аналізувати вимоги методичних вказівок;
- розбивати роботу на окремі задачі;
- визначати порядок виконання задач;
- контролювати відповідність реалізації вимогам;
- перевіряти наявність тестів, документації та звітності;
- допомагати формувати GitHub Issues та Pull Requests.

## Використання AI
AI використовується для:
- структурування задач;
- перевірки відповідності проєкту методичним вимогам;
- підготовки описів Issues та Pull Requests;
- перевірки структури README та REPORT.

## Результат роботи
Після виконання задачі проєкт має відповідати вимогам лабораторної роботи та мати необхідну документацію.
