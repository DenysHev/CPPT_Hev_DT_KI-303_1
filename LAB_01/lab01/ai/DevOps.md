# AI Role: DevOps

## Роль
DevOps відповідає за автоматизацію збірки, тестування та перевірку проєкту.

## Обов'язки
- налаштування Maven Wrapper;
- налаштування Maven-проєкту;
- налаштування GitHub Actions;
- автоматичний запуск тестів;
- запуск статичного аналізу SpotBugs;
- формування JAR-файлу;
- перевірка роботи проєкту на Ubuntu, Windows та macOS;
- налаштування завантаження JAR як GitHub Actions artifact.

## Використання AI
AI використовується для:
- підготовки конфігурації GitHub Actions;
- пошуку та виправлення помилок Maven;
- аналізу помилок CI;
- перевірки налаштувань Java 21;
- перевірки пакування executable JAR.

## Результат роботи
CI повинен автоматично виконувати перевірку проєкту, тести, статичний аналіз та пакування JAR-файлу.
